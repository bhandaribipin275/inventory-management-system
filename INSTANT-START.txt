Q: Do I need to run migrations?
A: NO! The database is already migrated and populated.

Q: Do I need to run populate_data.py?
A: NO! Demo data is already loaded in the database.

Q: Can I still register a new account?
A: YES! Go to /register/ and create your own account.

Q: What if I want to start fresh?
A: Delete db.sqlite3, run "python manage.py migrate", 
   then optionally "python populate_data.py"

Q: I see "18 unapplied migrations" warning
A: Ignore it! The database is already migrated. Django just 
   checks for new migrations. If you want to clear the warning,
   run: python manage.py migrate (it won't change anything)

Q: Port 8000 is in use
A: Run: python manage.py runserver 8080
