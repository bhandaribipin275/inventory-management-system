🎉 GOOD NEWS: This version includes a PRE-POPULATED DATABASE!
You can start the server immediately without running migrations or populate script!

METHOD 1: INSTANT START (FASTEST!)
===================================

Just install packages and run the server:

1. Install dependencies:
   pip install -r requirements.txt

2. Start server:
   python manage.py runserver

3. Open: http://127.0.0.1:8000

4. Login with:
   Email: admin@example.com
   Password: admin123

That's it! The database (db.sqlite3) is already included with demo data!


METHOD 2: FRESH SETUP (If you want to start from scratch)
===========================================================

If you want to create your own database from scratch:

1. Delete the existing database:
   rm db.sqlite3  (Mac/Linux)
   del db.sqlite3  (Windows)

2. Install dependencies:
   pip install -r requirements.txt

3. Run migrations:
   python manage.py migrate

4. Create admin user (optional):
   python populate_data.py

5. Start server:
   python manage.py runserver

6. Open: http://127.0.0.1:8000


METHOD 3: AUTOMATED SETUP
==========================

Windows:
1. Double-click: setup.bat

Mac/Linux:
1. chmod +x setup.sh
2. ./setup.sh


TROUBLESHOOTING
===============

Error: "18 unapplied migrations"
Solution: The pre-populated database is already migrated! Just run the server.
          If you deleted db.sqlite3, run: python manage.py migrate

Error: Port already in use
Solution: Run: python manage.py runserver 8080
